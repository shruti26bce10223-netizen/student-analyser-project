\# Student Performance Analyzer and Scholarship Management System



\## Overview

This Python project records student details and subject marks, calculates academic performance, checks scholarship eligibility, and stores student records in a JSON file.



\## Features

\- Add student details

\- Enter marks for four subjects

\- Calculate total marks and percentage

\- Assign a grade and pass/fail status

\- Identify the highest-scoring subject

\- Check scholarship eligibility





\## Technologies Used

\- Python

\- Visual Studio Code



\## Project Modules

\- `main.py` — Main menu and program workflow

\- `student.py` — Student information

\- `marks.py` — Marks and performance calculations

\- `validation.py` — Input validation functions

\- `scholarship.py` — Scholarship eligibility



\## How to Run

1\. Install Python.

2\. Open this project folder in Visual Studio Code.

3\. Open a terminal in the project folder.

4\. Run:



&#x20;  `py main.py`





\## Testing

Test the program by adding a student, entering marks, viewing saved students, searching by roll number, and checking invalid menu choices or marks.
